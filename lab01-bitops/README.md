## Part 4 · GPIO 寄存器模拟（25 分钟）

编辑 `bitops.c`，把刚才的宏用到一个真实场景里。用一个 `uint32_t` 当作 GPIO 控制寄存器：

| 位 | 含义 |

| bit0 | EN 使能 |
| bit2:1 | MODE 模式（2 bit） |

## 卡住时的提示（不是答案）

- 宏的所有参数都要加括号；宏整体也要加括号——尤其 `MASK` 这种带三元表达式的，不整体括起来接上 `<<` 会出优先级问题
- 用 `1U`，别用 `1`——带符号左移到 31 位是未定义行为
- `~` 是位取反，`!` 是逻辑取反（结果只有 0 和 1），它俩完全不是一回事
- `MASK(32)` 单独处理，因为 `1U << 32` 是未定义行为
- 判断 2 的幂：想一想 `n & (n - 1)` 会消掉哪一位
- 数 1 的个数：`n &= n - 1` 每执行一次消掉一个 1，循环几次就是几个 1
- 异或交换：`a ^= b; b ^= a; a ^= b;`
- 反转字节：可以循环取最低位拼到结果最高位，也可以查表
- 找唯一：相同的数异或两次会抵消，把整个数组异或起来试试
